# مرن للتحميل — أندرويد

نفس فكرة برنامج الويندوز (VideoDownloader) بس على الجوال، ويشتغل على yt-dlp:

- الصق روابط (رابط بكل سطر) من يوتيوب / تيك توك / تويتر / انستغرام ومئات المواقع.
- رابط قائمة تشغيل / قناة / صفحة موقع رئيسية → تطلع نافذة مربعات (صورة + اسم) تختار منها، مع «تحديد أول N» وحد أقصى 200.
- مواقع yt-dlp ما يعرفها → التطبيق يقرأ الصفحة نفسها ويطلّع المقاطع اللي فيها صور مصغّرة.
- بحث بالاسم: في يوتيوب، أو داخل الموقع اللي في الخانة الأولى (يستخدم خانة البحث حقت الموقع).
- جودة من 8K إلى 144p أو صوت فقط (MP3 / M4A).
- تحميل متزامن (1 إلى 16)، إيقاف مؤقت / استئناف، إعادة الفاشل.
- حفظ كملفات منفصلة أو كل شي في ملف ZIP واحد، داخل `التنزيلات/Murn`.
- يكمل التحميل بالخلفية مع إشعار تقدّم، وتقدر تشارك رابط من أي تطبيق للتطبيق مباشرة.

## البناء
البناء يصير تلقائياً على GitHub Actions (`.github/workflows/android.yml`) ويطلع `Murn-Downloader.apk`
في Release باسم `android-latest`.
لتوقيع ثابت (عشان التحديث ينزل فوق النسخة القديمة): أضف Secret باسم `MURN_KEYSTORE_B64` فيه keystore بصيغة base64
(alias `murn`، وكلمة السر `murn-downloader` للمفتاح والمخزن).
محلياً: `gradle assembleRelease` داخل مجلد `android` (يحتاج Android SDK و JDK 17).
